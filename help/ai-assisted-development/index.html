AI-assisted development

Get more from Claude Code and other AI tools, for less money and with fewer surprises.

For developers and teams using AI tools, or about toRemote or in person

/how

How I can help

Most teams install a coding agent and stop there. Costs climb, results vary from person to person, and nobody is sure what the agent is allowed to touch. I help you set it up so it knows your codebase and conventions, spends its context on what matters, and works inside clear limits. I use Claude Code every day for implementation, refactoring, tests and review, so this comes from practice.

What we look at

  • Context: a short, current CLAUDE.md, so the agent doesn't relearn your repo every session
  • Skills and MCP tools for the tasks you repeat, instead of long prompts
  • Cost: the right model for each job, and a clean context between tasks
  • Limits: what the agent may run, change or push, and how its changes get reviewed
  • Habits: plan first, keep diffs small, and let tests be the judge
