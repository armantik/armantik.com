How I can help

Most people use AI tools the way they came out of the box: default settings, the same long instructions typed every day, and one model for everything. That's level 1 of 5. Each level above it makes the tool cheaper to run and more useful, and I help you climb them, with Claude Code as the main tool. I use it every day for implementation, refactoring, tests and review, so this comes from practice.

/levels

The five levels

Each level builds on the one below. Most people stop at the first.

  1. Most people stop hereLevel 1Out of the boxA chat window or a coding agent on default settings. It starts from zero every session, and you type the same long prompts again.
  2. Level 2ContextThe agent knows your project: a short, current CLAUDE.md, the right files in view, and a clean context between tasks.
  3. Level 3Model and limitsA fast model for routine work, the strongest one for design and hard bugs. Clear permissions, so it works without constant questions.
  4. Level 4Skills and toolsSkills for the work you repeat, MCP tools for your issue tracker, database, docs and logs, and hooks that run your checks.
  5. Level 5A system that improvesOne setup the whole team shares in the repo. Cost and results are measured, and skills and context grow with your system.

Where it usually goes wrong

  • No skills: the same long instructions typed again and again, instead of a skill the agent loads when it needs it
  • Context left to chance: no CLAUDE.md at all, or one so long it costs tokens on every request
  • One model for everything: the most expensive model for simple edits, or a cheap one for hard design work
  • Too few tools: no MCP servers for the systems you use, so the agent guesses instead of looking
  • MCP used badly: too many servers and tools loaded at once, filling the context before the work starts
  • A setup that never improves: written once, then left behind while the codebase and the process move on
