How I can help

A good workshop leaves a team with something they can use the next morning. Each one mixes short talks with exercises your team works through in pairs, using examples from your own domain where possible. The Learning Lab guides are the material, so everyone can go back to them afterwards.

Topics

  • System design: from one server to many, with the case studies from the Casebook
  • Modern Java: virtual threads, records, pattern matching and the newer APIs worth knowing
  • AI engineering: MCP servers, RAG and agents inside a real backend
  • AI-assisted development: a Claude Code setup the whole team can share
