/how

How I can help

Early in a career it's hard to know what to learn next and what to ignore. We set a direction together from where you are and where you want to be, pick a few things to learn and build, and meet every few weeks to see how it's going. The usual topics are Java and the JVM, data structures, code reviews, debugging in production, and working well in a team.

What you get

  • A learning path made for you, not a generic roadmap
  • Feedback on your code and on how you work
  • Someone to ask when you're stuck
  • A starting point: the new joiners path in the Learning Lab
